핵심 디렉토리 & 역할

BE-fastapi
주식 데이터 API 백엔드

FastAPI 기반의 OHLCV 시세 제공 API, CORS 설정 및 헬스체크 엔드포인트 포함.

ag-grid-app
고성능 금융 데이터 프론트엔드

AG Grid를 활용한 실시간 주식 데이터 렌더링, 필터링, 차트 연동 웹 애플리케이션.

ohlcv-crawler
시세 데이터 수집 크롤러

일봉, 주봉, 분봉 시세를 수집하여 DB/S3에 저장하는 비동기 데이터 파이프라인.

EC2/LB/ECS
인프라 구축 & 거버넌스 스크립트

ALB 타겟 그룹 등록, ECS 태스크 정의, IAM 최소권한 정책 및 ECR 배포 스크립트 모음.
